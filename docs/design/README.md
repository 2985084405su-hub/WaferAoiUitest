## 设计要点（一句话版）

- 三项选项默认全不选；两个硬件选项互斥且允许都不选；运行中只读并展示快照。
- 27 步按章节列，状态同时用中文与颜色；失败/阻塞立即停止，其后保持“未执行”。
- 人工确认在页面内联完成，不用模态、不用本机弹窗；完成≠通过。
- 硬件未确认时显示“待现场处理”，占用不释放，页面无强制解锁。
- 永远显示 `27 / 184`，不宣称整条主流程通过。
