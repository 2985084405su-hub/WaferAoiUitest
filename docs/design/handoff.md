## 3. 必须实现的交互（验收点，逐条可测）

1. **选项默认全不选**；两个硬件项互斥，取消后回到“两项都不选”（`strict`），不是回到上一个选择。
2. **版本必填联动**：勾选“跳过版本断言”后，版本号/编译日期必填星号消失、错误清除、开始不被阻断；取消勾选立即恢复校验。
3. **开始执行**：按钮禁用时必须写原因（配置错误 / 本机忙 / 待现场处理 / 运行中）；点击后展示 runId 与选项快照，配置与选项转只读。
4. **实时状态**：步骤先进入“执行中”再出终态；等待人工显示“等待人工确认”；耗时每秒更新；不解析中文日志。
5. **失败/阻塞即停**：后续步骤保持“未执行”，不批量改跳过；清理阶段独立显示；清理未完成时结论不得显示全部成功。
6. **人工确认**：编号 + 名称 + checkpointId + 等待起点 + 已等待时长 + 操作说明 + 备注 + 完成/阻塞/失败；阻塞/失败必须填原因；提交后按钮禁用；过期/重复/已结束提交显示被拒绝且不改结果。
7. **刷新恢复**：断线显示“状态连接中断”，不得显示为测试失败；重连按 runId + sequence 去重补齐；确认点刷新后计时不重置。
8. **待现场处理**：占用未释放、禁止新一轮、无强制解锁；三项核验由后端返回，核验通过前“提交现场处理完成”禁用。
9. **历史**：只读、无旧确认按钮；证据缺失显示缺失态，不改写结论。
10. **范围文案常驻**：`本期 27 步 / 完整设计 184 步 / 其余 157 步未实现`；进度分母 27。
