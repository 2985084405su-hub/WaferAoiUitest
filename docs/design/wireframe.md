## 8. 状态机（步骤生命周期）

```mermaid
stateDiagram-v2
  [*] --> 未执行
  未执行 --> 执行中: step.started（先发布后执行）
  执行中 --> 成功: 自动断言通过
  执行中 --> 失败: 断言失败/执行异常
  执行中 --> 阻塞: 条件、能力或状态不可满足
  执行中 --> 等待人工确认: 到达原有人工点或人工策略点
  等待人工确认 --> 成功_人工: 现场完成 + 软件断言通过
  等待人工确认 --> 失败: 现场判定失败
  等待人工确认 --> 阻塞: 现场报告阻塞 / 确认超时
  未执行 --> 跳过_明确要求: 勾选跳过版本断言（仅 01.02）
  未执行 --> 跳过_整步硬件: 跳过硬件策略
  执行中 --> 跳过_部分硬件: 软件断言通过、硬件部分跳过
  执行中 --> 中断_结果未知: 执行器异常终止（无终态）
  失败 --> [*]
  阻塞 --> [*]
  跳过_明确要求 --> [*]
  跳过_整步硬件 --> [*]
  跳过_部分硬件 --> [*]
  中断_结果未知 --> [*]
```

规则：失败/阻塞/中断后不再进入“执行中”；页面不提供任何把终态改回成功或跳过的入口。
