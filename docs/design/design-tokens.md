# 设计令牌与布局规范（WAOI-MAINFLOW-WEB · 本期 01—06 节 27 步）

> 交付物：`tokens.css`（可直接引入）+ 本文档（取值理由与使用约束）。
> 唯一配色来源为 `tokens.css`；页面内不得出现未登记的颜色、字号、间距。
> 平台：桌面浏览器（测试机本机回环访问），主用分辨率 1920×1080 / 1536×864；最小支持宽度 1024。断点与触控/移动端不属于本期。

## 1. 色彩

### 1.1 中性

| 令牌 | 值 | 用途 | 白底对比度 |
| --- | --- | --- | --- |
| `--bg` | `#f2f4f7` | 页面底色 | — |
| `--surface` | `#ffffff` | 卡片、表格、弹层 | — |
| `--sunken` | `#f8fafc` | 次级容器、表头、只读区、准备检查 | — |
| `--line` | `#d0d5dd` | 输入框/按钮描边 | 非文本 |
| `--line-soft` | `#e4e7ec` | 分隔线、卡片描边 | 非文本 |
| `--ink-900` | `#101828` | 主文本（步骤名、结论标题） | 17.75:1 |
| `--ink-700` | `#344054` | 次主文本（表头、表单标签） | 10.46:1 |
| `--ink-600` | `#475467` | 正文说明、历史表格 | 7.69:1 |
| `--ink-500` | `#667085` | 辅助文本（原因、时间戳）——正文最浅色 | 4.97:1 |
| `--ink-400` | `#98a2b3` | **仅装饰**：占位符、分隔点、禁用图标 | 2.6:1（不得承载信息） |

### 1.2 主色

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--primary` | `#1a56c4` | 主按钮、当前步骤左边条、“开始执行”、链接 |
| `--primary-hover` | `#14459e` | 主按钮悬停 |
| `--primary-soft` / `--primary-line` | `#e9f0fd` / `#b9cdf4` | 选中行、严格执行策略条、当前步骤底纹 |

主色**只表示“可操作/当前”**，不表示结果；避免把“成功绿”和“主色蓝”混用。

### 1.3 语义色（需求 7.1 的四类结果 + 等待 + 中断）

| 语义 | 文本色 | 底纹 | 描边 | 文本对比度 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 成功（自动） | `#0f7b53` | `#e6f6ef` | `#b7e3cd` | 4.72:1 | 仅自动断言通过 |
| 成功·人工确认 | 同上 | 同上 | 同上 | 4.72:1 | 文案必须带“·人工确认”，不可只靠颜色区分 |
| 跳过（三类） | `#6f5a00` | `#fcf6e3` | `#e8dcb0` | 6.19:1 | 琥珀色而非灰色：跳过是“结果”，不是“无结果” |
| 阻塞 | `#9a3d00` | `#fdf0e7` | `#f0cdb5` | 6.18:1 | 与失败区分：阻塞=条件/能力/确认不满足 |
| 失败 | `#b3261e` | `#fdecea` | `#f3c3bf` | 5.72:1 | 断言失败/执行异常，必须保留原始原因 |
| 等待人工确认 | `#0b5cad` | `#e8f2fd` | `#bcd7f4` | 5.89:1 | 进行中，不得与阻塞同色 |
| 中断·结果未知 | `#5b4a86` | `#f1edfa` | `#d5cbec` | 6.59:1 | 紫灰=“不确定”，避免被读成失败或跳过 |
| 未执行 | `#475467` | `#eef1f5` | `#dde2e9` | 7.69:1 | 中性，明确“未开始≠跳过” |

补充规则：

1. 跳过用琥珀、不用灰：灰色会与“未执行”混淆，而跳过是已得出结论的状态。
2. 阻塞（橙）与失败（红）必须可区分，因为后续处置不同：阻塞常对应“待现场处理”，失败对应断言不成立。
3. 状态色**从不单独使用**：徽标必须带中文文字；进度条分段带计数文字；当前步骤另有左侧 3px 边条与环形“执行中”图标。
4. 红/绿不共用同一元素的双重含义（例如“开始执行”按钮永不变红）。

### 1.4 色觉障碍与打印

- 状态徽标同时具备：文字 + 圆点 + 底色；删除颜色后仍可读。
- 打印时保留文字与边框，隐藏演示条、顶栏与右侧详情（见原型 `@media print`）。

## 2. 排版

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--font-sans` | Segoe UI Variable / Segoe UI / 系统 CJK | 全部 UI 文本 |
| `--font-mono` | Cascadia Mono / Consolas | runId、checkpointId、路径、耗时、日志、stepId |
| `--fs-11` | 11px | 徽标、标签、原因、元信息（不小于 11px） |
| `--fs-12` | 12px | 辅助说明、表格、表单标签 |
| `--fs-13` | 13px | 正文、控件、步骤名 |
| `--fs-14` | 14px | 卡片标题、主按钮 |
| `--fs-16` | 16px | 页面标题（顶栏） |
| `--fs-20` | 20px | 计数数字、进度分子 |
| `--lh-tight` / `--lh-body` | 1.25 / 1.55 | 标题 / 正文 |

规则：

- 数字一律 `font-variant-numeric: tabular-nums`，避免耗时/计数跳动导致行宽抖动。
- 不使用 300/700 以外的字重跳变；中文标题 650、正文 400、强调 600。
- 中英混排不插入空格；路径与 ID 用等宽字体并允许 `overflow-wrap:anywhere`。
- 单行信息不压缩到 10px 以下；页面密度靠间距控制，不靠缩小字号。

## 3. 间距、圆角、阴影

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--sp-1…--sp-7` | 4 / 8 / 12 / 16 / 24 / 32 / 48 | 组件内间距、区块间距、页面留白 |
| `--r-sm` | 4px | 徽标、标签、日志块 |
| `--r-md` | 6px | 输入框、按钮、提示条、人工确认说明块 |
| `--r-lg` | 10px | 卡片、弹层、人工确认卡 |
| `--shadow-1` | `0 1px 2px rgba(16,24,40,.06)` | 卡片静止 |
| `--shadow-2` | `0 10px 28px -16px rgba(16,24,40,.28)` | 人工确认/待现场处理卡（需要抢注意力） |

层叠关系（z-index）：顶栏 40 < 章节吸顶 5（相对滚动容器）< 弹层 80 < Toast 90。卡片不使用阴影堆叠制造层级，层级靠底色与描边。

## 4. 布局与栅格

```
┌───────────────────────────────────────────────────────────────┐
│ 顶栏 56px：标题 · 范围徽标 · 本机占用 · 连接状态 · 历史运行      │
├───────────────────────────────────────────────────────────────┤
│ 左 360   │            中 minmax(0,1fr)          │  右 384      │
│ 配置      │ 阶段步进 / 汇总计数 / 人工确认卡      │ 步骤详情      │
│ 运行选项  │ 待现场处理卡                          │ 断言          │
│ 开始执行  │ 27 步章节清单                         │ 日志          │
│ 准备检查  │ 本轮结论                              │ 证据 / 图例   │
│ 本轮快照  │                                       │              │
└───────────────────────────────────────────────────────────────┘
```

- 容器最大宽度 1920px，水平内边距 24px，栅格间距 16px。
- 断点：
  - `>1560px`：三栏（360 / 1fr / 384）。
  - `1180–1560px`：两栏，右栏下移为整行“详情”，仍可在同一屏内滚动查看。
  - `≤1180px`：单栏堆叠；步骤行隐藏耗时列（详情内仍显示）。
- 右栏 `position:sticky; top:72px`，保证滚动步骤时日志一直可见；人工确认卡位于中栏清单上方，不使用浮层，避免被误认为模态阻断。
- 章节头 `position:sticky; top:56px`，长清单（27 步）滚动时保留章节上下文。
- 行高：步骤行约 40–46px，一屏（1080 高）可见约 15 行，符合“27 步 + 详情”同屏评估。

## 6. 动效

| 场景 | 处理 |
| --- | --- |
| 执行中图标 | 8×8 环形旋转，800ms/圈；不使用整行闪烁 |
| 进度条/分段 | 180ms 宽度过渡 |
| Toast | 180ms 淡入 + 8px 上移 |
| 状态切换 | 仅底色与徽标替换，不整行位移（避免长时值守时视觉跳动） |
| 减少动效 | `prefers-reduced-motion` 下关闭所有动画 |
